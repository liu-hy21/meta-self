# 页面模式

开始排页前读取 [参考页证据](../../references/source-study.md) 和 [可视化数据与空间逻辑](../../references/visualization-logic.md)。

## 典型排布

| 页面模式 | 空间结构 | 适合回答的问题 | 代表页 |
| --- | --- | --- | --- |
| 端到端链路 | 来源按行，阶段按列，左到右追踪 | 数据从哪里来，经过什么，落到哪里 | 隐私采集第3页、数据平台融合第11页 |
| 编号流程 | 编号步骤按顺序排列，控制点贴近步骤 | 事情怎样发生 | 隐私采集第4页、VHR第2页底部 |
| 分层架构 | 能力层纵向堆叠，平台或区域横向分列 | 哪些能力共用、独有或依赖 | SDA融合第5、15页、VHR第6页 |
| 平台全景矩阵 | 平台为列，数据域/技术栈/部署为行 | 平台定位和重叠在哪里 | 数据平台融合第4页 |
| 区域部署图 | 国内/海外分区，区域和站点作为空间节点 | 平台如何覆盖不同区域 | SDA融合第4、15页 |
| 左图右表 | 左侧定位结构或缺口，右侧按维度对标 | 差距具体体现在哪里 | VHR第5页、数据平台融合第5页 |
| 角色价值图 | 角色等宽并列，任务、能力、结果纵向对应 | 平台为谁创造什么价值 | VHR第2页、数据平台融合第15页 |
| 问题机制图 | 问题源头向成本、效率、体验或治理后果展开 | 为什么需要改变 | SDA融合第6–13页、VHR第4页 |
| 趋势与测算 | 趋势图/方案图配关键数字和测算表 | 方案收益是否可信 | SDA融合第8页、数据平台融合第5、10页 |
| 场景清单 | 类别分行，场景、标准、风险或说明分列 | 哪些场景可管理和验收 | VHR第3、7页、数据平台融合第19页 |
| 责任矩阵 | 工作项、牵头、配合、时间、交付物分列 | 接下来谁在何时做什么 | VHR第8页、SDA融合第20、21页 |

一个页面只设置一个主关系。组合页面应使用“页首判断 + 主图 + 证据表/口径区”，而不是把多个独立卡片平均铺满画布。
