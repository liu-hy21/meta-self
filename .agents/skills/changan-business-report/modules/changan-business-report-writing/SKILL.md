# 业务写法

开始写文案前读取 [业务叙事与措辞](../../references/business-writing.md)。

采用“对象—动作—影响”的句式，具体说明哪类数据、哪套系统、哪个角色、哪项业务受到什么影响。技术能力尽量落到使用动作：

```text
数据/信号 → 分析能力 → 可交付信息 → 使用者动作 → 业务结果
```

总览页先说对象和边界，流程页再说动作和顺序。车云隐私数据采集第3页的“采集触点—数据内容—传输系统—存储地”和第4页的“确认—开发—更新—授权—采集—存储—使用”是这种写法的代表。

保留“预计、约、方案、部分、国内/海外、本阶段”等限定条件。删掉没有证据的“全面、深度、持续赋能、行业领先”等空泛修饰。对标表每一行只比较一个维度，不能左侧写问题、右侧写口号。
